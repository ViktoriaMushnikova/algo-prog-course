1. В C# большинство ошибок и ошибок типов вылезают еще на этапе компиляции. В Python код выполняется строчка за строчкой, поэтому ошибки часто всплывают во время работы.
2. Состоит из двух шагов - сначала dotnet build, а затем запуск полученного исполняемого файла.
3. В obj/ лежат временные файлы для сборки, а в bin/ - уже готовый скомпилированный результат. В Git их не коммитят, потому что это мусор. Эти файлы автогенерируются и у каждого разработчика собираются заново.
4. commit сохраняет изменения локально на компьютере, а push отправляет эти сохраненные коммиты на удаленный сервер.
5. Конкатенация просто склеивает строки через плюс, а интерполяция позволяет удобно вставлять переменные прямо внутри строки. Интерполяция предпочтительнее - код выглядит чище, читается проще и работает чуть эффективнее.
6. Произойдет целочисленное деление - дробная часть просто отбросится. Чтобы исправить, нужно привести хотя бы один операнд к типу плавающей точки
7. Значение const задается один раз при объявлении и его нельзя изменить во время работы программы. Использовать стоит для неизменяемых значений, например const double weight = 59.1 или const int weight = 60.
8. Top-level statements позволят писать код сразу в файле без создания класса Program и метода Main(). Это помогает чтобы не писать лишний шаблонный код, хотя под капотом компилятор всё равно сам создаёт эту структуру.
